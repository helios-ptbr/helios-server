Documentação

A tecnologia do Helios Voting se baseia em técnicas criptográficas avançadas, revisadas por especialistas, que mantêm o seu voto secreto e oferecem um código de rastreamento inteligente para você conferir se a sua cédula foi recebida e contada corretamente:

  • manual do usuário (em inglês), para quem administra eleições e para quem vota
  • como o Helios funciona (em inglês)
  • arquitetura (em inglês), para quem desenvolve
  • artigo original, revisado por especialistas (Usenix Security 2008) (em inglês)
  • Pyrios, uma biblioteca em Go de Tom Roeder que verifica eleições do Helios.
  • Helios Election Monitor, produzido pela Universidade Católica de Louvain.
