# Manuais do apurador

Para quem é apurador da eleição. O apurador guarda uma parte da chave que abre o resultado.

**Atenção:** o Helios não tem quórum. Todos os apuradores precisam decifrar. Se um perder a chave, o resultado não abre e não há como recuperar.
